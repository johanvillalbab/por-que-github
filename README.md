# por-que-github · Bloque 1 del workshop "GitHub para diseñadores"

Nombre propuesto del repositorio: `por-que-github`.

Este repositorio acompaña el bloque 1 (Contexto) del workshop gratuito "GitHub para diseñadores" de Interface School. Es el punto de partida de la sesión: explica qué te llevas, qué es un repositorio y por qué GitHub le sirve a quien diseña.

La práctica (crear tu repositorio, hacer un commit y abrir un pull request) no está aquí. La práctica está en el repositorio plantilla del taller.

> Este repositorio es público. Si creas uno parecido, no subas datos de clientes ni información confidencial.

## Diseño del bloque

**Objetivo observable.** Al terminar el bloque, sabes qué te llevas de la sesión (tu repositorio, un commit con un buen mensaje y tu pull request abierto) y respondes en el chat si ya tienes cuenta de GitHub.

**Nivel.** Principiante. Es para diseñadoras y diseñadores sin experiencia previa con Git. Todo se hace en el navegador, en computador o celular. No se instala nada ni se usa la terminal.

**Duración.** 5 minutos, en el primer bloque del taller.

**Cómo se evalúa.** Con el chequeo en el chat: cada persona escribe "Sí" o "Todavía no" según tenga o no cuenta de GitHub. Es una evaluación formativa: sirve para ajustar el ritmo de la sesión y no pone nota. Este bloque no tiene evidencia propia; la evidencia de la sesión es el enlace del pull request, que se produce más adelante.

**Concepto del bloque.** Uno solo: repositorio.
